Welcome to my new Hugo website! This is a basic setup without any theme, giving me complete control over the design and functionality.

## What is Hugo?

Hugo is a fast and modern static site generator written in Go. It's perfect for building:

- Personal blogs
- Documentation sites
- Portfolio websites
- Corporate websites

## Features of This Site

This basic Hugo setup includes:

- **Clean, responsive design** - Works great on all devices
- **Custom CSS styling** - No theme dependencies
- **Pagination support** - For blog posts and content lists
- **Tag system** - Organize content with tags
- **404 error page** - Custom error handling
- **RSS feed** - Automatic RSS generation

## Getting Started

To run this site locally:

```bash
hugo server -D
```

Then visit `http://localhost:1313` to see your site in action.
